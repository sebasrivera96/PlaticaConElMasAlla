# PlaticaConElMasAlla

A time capsule for sharing knowledge and reflections on all kinds of books.

## About

This website is a space where a group of friends share reflections and ideas that come up during book club sessions. It started as a static website built with HTML, CSS, and React (TypeScript), but it could grow to be dynamic with cloud provider integration and database functionality.

## Tech Stack

- **React** - UI library
- **TypeScript** - Type-safe JavaScript
- **Vite** - Build tool and dev server
- **CSS** - Styling

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sebasrivera96/PlaticaConElMasAlla.git
cd PlaticaConElMasAlla
```

2. Install dependencies:
```bash
npm install
```

### Development

Run the development server:
```bash
npm run dev
```

The site will be available at `http://localhost:5173`

### Build

Create a production build:
```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

Preview the production build locally:
```bash
npm run preview
```

### Linting

Run the linter:
```bash
npm run lint
```
